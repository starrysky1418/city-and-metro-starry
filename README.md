# Starry 版 1.0

基于 VinsonFung 的《城市与地铁》制作的非商业社区修改版。保留原版的地铁规划、客流模拟与城市经营玩法，新增地图并扩展建设和运营工具。

## 地图与历史

- 新增新加坡（1985）、深圳（2000）、南京（2000）和苏州（2010）。苏州包含吴江、昆山城区和苏南硕放机场。
- 扩展广州和上海。广州增加佛山核心区、花都、从化城区、增城和南沙等走廊。上海增加嘉定、青浦、松江、金山、奉贤、临港及昆山方向。
- 社区地图采用 OpenStreetMap 地理数据，按场景配置人口、岗位、枢纽和历史事件。新加坡补充兀兰延长线、F1 和综合度假区，深圳补充大运会及机场航站楼迁移，南京补充青奥会及江北新区。
- 为社区城市配置合同。部分片区覆盖目标以可选挑战形式出现。

## 建设与运营

- 草案可按线路和区段选择建设，先实施选中的新建区段。面板显示分段预算。
- 可调整车站位置和标高，付费改造已建车站，并通过扩容提高车站承载能力。
- 区间可设置高程变化。线路草案可从不同端推进，自动编号避开已使用的线路名。
- 车站总览支持查看商业开发预测，并批量开发选定车站。
- 列车界面显示可用车型和各线配车，可选择每月自动购买缺失列车。
- 车站详情分列进站、出站和站内换乘，并显示站外换乘的步行距离、预计时间及当前客流。
