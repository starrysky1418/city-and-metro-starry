## Starry 版 1.0（2026-11-11）

首版更新日志记录新加坡、深圳、南京、苏州及广州、上海扩图；纽约与最近一轮票价调整见上方 1.1。

### 地图与历史

- 新增新加坡（1985）、深圳（2000）、南京（2000）和苏州（2010）。苏州包含吴江、昆山城区和苏南硕放机场。
- 扩展广州和上海。广州增加佛山核心区、花都、从化城区、增城和南沙等走廊，补上黄埔至增城之间的建设走廊。上海增加嘉定、青浦、松江、金山、奉贤、临港及昆山方向。
- 社区地图采用 OpenStreetMap 地理数据，按场景配置人口、岗位、枢纽和历史事件。新加坡补充兀兰延长线、F1 和综合度假区，深圳补充大运会及机场航站楼迁移，南京补充青奥会及江北新区。
- 为社区城市配置合同。部分自由度较高的片区覆盖目标以可选挑战形式出现。

### 建设与运营

- 草案可按线路和区段选择建设，先实施选中的新建区段；面板显示分段预算。允许同一条线从不同端推进，自动编号避开已使用的线路名。
- 可调整车站位置和标高，付费改造已建车站，并通过扩容提高车站承载能力；区间可设置地下、地面和高架之间的高程变化。
- 车站总览支持查看商业开发预测，并批量开发选定车站；列车界面显示可用车型和各线配车，可选择每月自动购买缺失列车。
- 车站详情分列进站、出站和站内换乘，并显示站外换乘的步行距离、预计时间及当前客流。中国城市的自动站名优先选用合适的道路名，社区名作为后备。

### 版本交付与验证

- 整理 Starry 版 1.0 的更新日志、原作者署名、许可证和第三方资料说明，并制作宣传片，展示深圳、苏州、新加坡和南京地图，以及分段开通、车站标高和位置调整、批量商业开发等操作。
- 地图和功能迭代结合实际游玩反馈进行。地图人口、岗位和财政采用剧本参数，历史资料用于校准关键年份、设施和票价。

## 原版基线 v2.5.1

原版以真实城市和历史年代为背景，提供九座真实城市和青湾教程；已具备建设效果预测、居住与就业分布、客流与拥堵分析、历史事件、分期开放、政府合同和站内商业等机制。居民会根据线路可达性、出行时间和票价选择交通方式，城市人口和就业随年代及交通条件变化。这些系统构成社区地图和功能扩展的基础。

## 关于数据与验证

地图人口、岗位和财政采用剧本参数，历史资料用于校准关键年份、设施和票价；开通年份参照公开年表，客流、造价与几何量中的估算部分在 `THIRD_PARTY_NOTICES.txt` 标注来源。每轮迭代检查全部 15 张地图的开局配置，并对预置站名、自动命名与旧存档迁移做专项测试。
